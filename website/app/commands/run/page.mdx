# hty run

Start a program in a new detached PTY session. The session runs in the background — use `watch`, `snapshot`, or `attach` to interact with it.

## Synopsis

```sh
hty run [flags] -- <program> [args...]
```

## Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--name` | string | | A human-friendly name for the session. Must be unique across all live sessions. |
| `--rows` | number | `24` | Terminal height in rows. |
| `--cols` | number | `80` | Terminal width in columns. |
| `--scrollback` | number | `10000` | Number of lines to retain in the scrollback buffer. |
| `--cwd` | string | | Working directory for the spawned program. |
| `-d`, `--detach` | boolean | | Accepted as a no-op for familiarity (sessions are always detached). |

## Examples

```sh
# Simple session
hty run -- vim /tmp/notes.txt

# Named session with custom terminal size
hty run --name my-vim --rows 40 --cols 120 -- vim /tmp/notes.txt

# With working directory
hty run --name build --cwd /my/project -- npm test
```

<Callout type="info">
The `--` separator is required when passing arguments to the program. Without it, hty cannot distinguish its own flags from the program's arguments.
</Callout>
